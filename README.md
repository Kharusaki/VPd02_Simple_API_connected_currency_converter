# Конвертер валют (Simple API-connected currency converter)

Консольная программа для работы с курсами валют. Получает актуальные курсы
от бесплатного сервиса [open.er-api.com](https://open.er-api.com/), сохраняет
их в кэш-файл `currency_rate.json` и позволяет выполнять конвертацию сумм
между валютами.

Проект выполнен в рамках домашнего задания по уроку **VPd02 «Документация и
форматы данных»** (базовая часть + бонусы 5–7).

## Возможности

- выбор базовой валюты (любой код в кодах ISO 4217, например `USD`, `EUR`, `RUB`);
- вывод курсов `RUB`, `EUR`, `GBP` относительно выбранной базовой валюты;
- конвертация произвольной суммы между двумя валютами (через базовую валюту);
- кэширование ответа API в файл `currency_rate.json` на 24 часа — при повторном
  запуске сетевой запрос не выполняется, если кэш свежий и базовая валюта та же;
- понятные сообщения об ошибках на русском языке (нет сети, ошибка API,
  неверный код валюты, недоступный файл и т. д.);
- модульная структура: сеть, хранилище и интерфейс разделены по файлам.

## Структура проекта

| Файл                | Назначение                                                     |
|---------------------|-----------------------------------------------------------------|
| `currency.py`       | Базовая программа: получение курсов, кэширование, вывод курсов. |

| `api_client.py`     | Работа с API open.er-api.com (сетевые запросы и обработка ошибок). |

## Требования

- Python 3.10+ (проект проверен на Python 3.12);
- пакет `requests`.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Базовая версия

```bash
python currency.py
```

Программа попросит ввести базовую валюту и выведет курсы RUB, EUR, GBP.
Пустой ввод (Enter) завершает работу.

### Расширенная версия (с конвертером)

```bash
python cli.py
```

1. Введите базовую валюту, например `USD`.
2. Посмотрите курсы `RUB`, `EUR`, `GBP`.
3. Ответьте `y`, чтобы конвертировать сумму, и укажите:
   - из какой валюты (например `USD`);
   - в какую валюту (например `RUB`);
   - сумму (например `100` или `12.5`).

Программа выведет результат, например:

```
100.0000 USD = 8624.4300 RUB
```

Пример работы:

```

или просто нажмите Enter, чтобы выйти.

  RUB: 86.2280
```

## Как работает кэш

- Ответ API сохраняется в `currency_rate.json` в корне проекта.
- Файл считается свежим в течение 24 часов (`CACHE_MAX_AGE` в `storage.py`).
- Если кэш свежий и его `base_code` совпадает с запрошенной валютой — программа
  использует данные из файла без обращения к сети.
- Если кэш устарел, отсутствует или не подходит по валюте — данные обновляются
  и файл перезаписывается.

## Используемый API

- Сервис: [open.er-api.com](https://open.er-api.com/)
- Документация: [https://www.exchangerate-api.com/docs](https://www.exchangerate-api.com/docs/free)
- Пример запроса: `https://open.er-api.com/v6/latest/USD`

## Структура JSON-кэша

Кэш хранит ответ API в читаемом виде (`ensure_ascii=False`, отступ 4 пробела):

```json
{
    "result": "success",
    "base_code": "USD",
    "conversion_rates": {
        "USD": 1.0,
        "RUB": 86.2280,
        "EUR": 0.8600
    }
}
```

Примечание: сервис в текущей версии отдаёт курсы в поле `rates`, в документации
используется `conversion_rates`. Программа приводит ответ к единому ключу
`conversion_rates` для использования внутри кода.
